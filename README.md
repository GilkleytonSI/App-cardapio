# 📌 Gil Burguer - A Melhor Hamburgueria!

Bem-vindo ao repositório do **Gil Burguer**, a melhor hamburgueria da região! Este projeto é um site simples e responsivo para exibir o cardápio da hamburgueria, permitindo que os clientes adicionem itens ao carrinho e finalizem pedidos via WhatsApp.

## 🚀 Visão Geral

O site do **Gil Burguer** foi desenvolvido com o objetivo de proporcionar uma experiência de usuário agradável e funcional. Ele permite que os clientes visualizem o cardápio, adicionem itens ao carrinho, e finalizem o pedido diretamente pelo WhatsApp. O site é totalmente responsivo, garantindo uma boa experiência em dispositivos móveis e desktops.

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estrutura do site.
- **CSS3**:  Estilização com Tailwind CSS.
- **JavaScript**: Funcionalidades interativas como adicionar/remover itens do carrinho e finalizar pedidos.
- **Tailwind CSS**: Framework CSS utilitário para estilização rápida e responsiva.
- **Toastify-js**: Biblioteca para exibir notificações toast.
- **Font Awesome**: Ícones utilizados no site.

## 🎯 Funcionalidades

✅ **Cardápio Interativo**: Os clientes podem visualizar os hambúrgueres e bebidas disponíveis, com descrições e preços. <br>
✅ **Carrinho de Compras**: Os clientes podem adicionar e remover itens do carrinho, visualizando o total do pedido. <br>
✅ **Finalização de Pedido**: O pedido pode ser finalizado via WhatsApp, enviando uma mensagem pré-formatada com os itens selecionados e o endereço de entrega. <br>
✅ **Verificação de Horário**: O site verifica se o restaurante está aberto e exibe um aviso caso esteja fechado. <br>

## 📂 Estrutura do Projeto

```
/
├── styles/
│   ├── output.css      # Arquivo gerado pelo Tailwind CSS com todas as classes utilitárias.
│   ├── style.css       # Arquivo CSS principal, que importa o Tailwind CSS.
├── assets/             # Diretório de imagens do site
├── index.html          # Página principal do site, contendo a estrutura HTML e links para os recursos necessários.
├── script.js           # Contém toda a lógica JavaScript para interatividade do site, como adicionar/remover itens do carrinho e finalizar pedidos.
├── tailwind.config.js  # Configuração do Tailwind CSS, incluindo fontes e imagens de fundo.
└── README.md           # Documentação do projeto
```

## 🚀 Personalização

✅ **Cardápio**: Para adicionar ou remover itens do cardápio, basta editar o arquivo `index.html` na seção de menu. <br>
✅ **WhatsApp**: Para alterar o número de telefone para onde os pedidos são enviados, edite a variável `phone` no arquivo `script.js`. <br>
✅ **Horário de Funcionamento**: O horário de funcionamento é verificado pela função `checkRestaurantOpen()` no arquivo `script.js`. Você pode ajustar os horários conforme necessário. <br>
